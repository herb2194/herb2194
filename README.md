## 🔍 Troubleshooting

| 문제 | 해결 |
|---|---|
| 다중 시청자 연결 오류 | WebRTC offer·answer·ICE candidate 전달 흐름과 signaling 구조를 점검하여 Host ↔ Viewer 연결 흐름 개선 |
| 실시간 이벤트 충돌 | 라이브 / 1:1 채팅 Socket.IO 이벤트 흐름을 분리하여 이벤트 범위 명확화 |
| 결제 · 포인트 · 알림 순서 문제 | 상태 변경 → 포인트 적립 → 알림 발송 흐름으로 순차 처리 구조 구성 |
